Quy tắc làm việc:

1. Trước khi code luôn chạy git pull.
2. Mỗi người chỉ làm trong thư mục mình phụ trách:
- backend-csharp/
- backend-ruby/
- frontend-react/
- database/ chỉ sửa khi cả nhóm thống nhất.
3. Làm xong phần nào chạy được thì git add ., git commit -m "ghi rõ đã làm gì", rồi git push.
4. Không push file rác như node_modules/, bin/, obj/, .env, .vs/, .idea/.
5. Không tự ý sửa file SQL cuối.
6. Nếu bị lỗi Git/API/SQL thì báo ngay, không sửa lung tung.
